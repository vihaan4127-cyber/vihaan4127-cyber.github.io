Projects & Interactive Work

APCS Final Project: Pokémon FireRed Engine

A polished HTML5 Canvas fan-made recreation of the FireRed opening, with smooth tile movement, four-way facing, original pixel-art sprites, and researched Kanto map layouts.

POKÉMON FIRE RED KANTO OPENING · FAN-MADE GAME
Controls Move: Arrow Keys / WASD A button: Z / Enter / Space — interact, confirm, advance B button: X — back or cancel menus

Play through Red’s house, Pallet Town, Professor Oak’s Lab, and Route 1. Withdraw the Potion from the PC, choose Bulbasaur, Squirtle, or Charmander, battle Blue, and encounter Pidgey or Rattata. Original Canvas sprites use canonical character and Pokémon names.

Download Java Project (.JAR)

Objectives & Scope

  • Developed a custom Java game engine handling 2D tile-based movement and collisions.
  • Implemented turn-based battle mechanics with Pokémon stats and damage formulas.
  • Programmed narrative cutscenes: Player house, Professor Oak introduction, and Starter choice (Charmander, Squirtle, Bulbasaur).
  • Built local save and load state management.

World System & Collision Logic

  • Pixel grid overworld system managed by a Boundary Manager class.
  • Resolved sprite movement glitches into walls by building a strict grid-locking mechanism that stops player movement until target tiles are reachable.

Technical Outcomes & Growth

  • Navigated AI engineering bottlenecks regarding context windows, file size limits, and prompt structure.
  • Mastered complex State Machine architecture (Title, Overworld, Battle, and Menu states).
